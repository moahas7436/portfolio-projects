# Marvel Character Power Analysis

This project explores the traits, alignments, and power levels of Marvel characters using a fictional dataset.  
The goal is to practice real data science skills through a fun and familiar lens — turning superheroes into a learning opportunity.

---

## Key Features

- Created a custom dataset of Marvel characters
- Analyzed average power levels across teams and alignments
- Visualized individual power levels using bar charts
- Simulated team performance comparisons using `.groupby()`

---

## Insights

- **Thor and Hulk** had the highest individual power levels
- **Avengers** had the strongest average team power
- Most characters were aligned as **heroes**, with only one villain (Loki)
